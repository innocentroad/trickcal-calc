# Trickcal Damage Calculator (トリッカル ダメージ計算機)

グローバル板トリッカルの戦闘メカニクスに基づいた、ダメージおよび会心計算シミュレーターです。

## 主な機能
- **高精度な計算数式**: ゲーム内データ解析から導き出された、基本ダメージ・会心発生率・会心倍率の区分的有利関数を実装しています。
- **敵プリセット機能**: 今後主要な敵のステータスをワンクリックで反映できるようにする予定。
- **クレヨン比較シミュレーション**: クレヨンやフォローなどの強化によるダメージの伸び率（期待値の変化）を比較できます。
- **動的グラフ表示**: 攻撃力や防御力の変化に伴うダメージ推移をグラフで視覚化します。

## 使い方
1. 左側のパネルに、使用するキャラクターのステータスを入力します。
2. 防御側のセクションで敵のプリセットを選択するか、手動で防御ステータスを入力します。
3. 装備やバフによる補正がある場合は「追加%」セクションに入力します。
4. 右側のパネルに計算結果（通常・会心・期待値）と、ステータス変動によるグラフが表示されます。

## 実装の詳細
本シミュレーターは以下の数式モデルを使用しています。
- **基本ダメージ**: 10/3定数を用いた有理関数モデル。
- **会心発生率**: 防御側による2倍のペナルティ補正を考慮したモデル（上限80%）。
- **会心倍率**: 175%を境界点とする高精度な区分的有理関数モデル。
